FitMatch Backend API Documentation

Explore some FitMatch backend API endpoints and their functionalities.

API Endpoints

Trainer Endpoints

  • GET /trainers: Retrieve a list of all trainers.
  • GET /trainers/{id}: Retrieve details of a specific trainer by ID.
  • POST: /trainers Create a new trainer.
  • PUT: /trainers/{id} : Update an existing trainer by ID.
  • DELETE: /trainers/{id} : Delete a trainer by ID.

Training Service Endpoints

  • GET /training-services: Retrieve a list of all training services.
  • GET /training-services/{id}: Retrieve details of a specific training service by ID.
  • GET /trainers/{trainerId}/training-services: Retrieve all training services offered by a specific trainer.
  • GET /training-services/search?query={category}: Search for training services by category.
  • POST: /training-services Create a new training service.
  • PUT: /training-services/{id} : Update an existing training service by ID.
  • DELETE: /training-services/{id} : Delete a training service by ID.

Training Session Endpoints

  • GET /training-sessions: Retrieve a list of all training sessions.
  • GET /training-sessions/{id}: Retrieve details of a specific training session by ID.
  • GET /training-sessions/customer/{customerId}: Retrieve all training sessions for a specific customer.
  • POST: /training-sessions Create a new training session.
  • PUT: /training-sessions/{id} : Update an existing training session by ID.
  • DELETE: /training-sessions/{id} : Delete a training session by ID.

Review Endpoints

  • GET /reviews/customer/{customerId}: Retrieve all reviews for a specific customer.
  • GET /reviews/{id}: Retrieve details of a specific review by ID.
  • GET /trainers/{trainerId}/reviews: Retrieve all reviews for a specific trainer.
  • POST: /reviews Create a new review.
  • PUT: /reviews/{id} : Update an existing review by ID.
  • DELETE: /reviews/{id} : Delete a review by ID.
